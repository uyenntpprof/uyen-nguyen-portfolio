## Publish with GitHub Pages

1. Make sure the repository is **public** (Settings → General → Danger Zone → Change visibility).
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, pick the branch (e.g. `main`) and folder **/ (root)**, then **Save**.
4. After about a minute the site is live at `https://<github-username>.github.io/uyen-nguyen-portfolio/`.

The consulting page lives at `https://<github-username>.github.io/uyen-nguyen-portfolio/consulting.html`.
